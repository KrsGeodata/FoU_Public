# Resource list:

## Kart:

**Proffkart**:
<br> **Description**: Brukes for å se reguleringsplaner, kommuneplaner og sjekke plassering av bygg.
<br> **Datatypes**:
<br> **Can be found**:

**Gisline**:
<br> **Description**: Tyngre kartverktøy med mer funksjonalitet. Brukes for matrikkelsjekking og når man trenger mer detaljert informasjon.
<br> **Datatypes**:
<br> **Can be found**:

**Arealplaner**:
<br> **Description**: Offentlig nettside som viser reguleringsplaner for hele Norge. Viser også innlagte dispensasjoner i kartform. Planforvaltningsavdelingen legger inn alle dispensasjoner her slik at de blir synlige for alle.
<br> **Datatypes**:
<br> **Can be found**: https://www.Arealplaner.no

**NVE-kart**:
<br> **Description**: Kartverktøy som viser fareområder for flom, skred og kvikkleire. Avgjørende for å vurdere om bygg kan oppføres på stedet.
<br> **Datatypes**:
<br> **Can be found**: https://www.nve.no/kart/

**Askeladden**:
<br> **Description**: Spesialverktøy for kulturminner. Brukes når man må sjekke om det er vernede kulturminner på eller nær eiendommen.
<br> **FileTypes**: FGDB, GML, SOSI. (PostGIS --> GeoJSON, GML, WKB/WKT, Shapefile)
<br> **Datatypes**: Freda bygninger, Kulturmiljøer
<br> **Can be found**: katalog.geonorge.no/metadata/kulturminner-askeladden/b05e2fc7-1f16-4533-99b0-737fd7cfedc9

Miljødirektoratets kartverktøy:
<br> **Description**: To alternative kart: Naturbase og Miljøstatuskart. Viser truede arter, naturtyper og miljømessige forhold som må vurderes ved bygging.
<br> **Datatypes**:
<br> **Can be found**: https://geocortex02.miljodirektoratet.no/vertigisstudio/web/?app=a3a09afee5c24c459c53a9a9ff0915f1
