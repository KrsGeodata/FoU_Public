## Ways of Working
- **Sprints:** 2 weeks each (3 sprints per PI)  
- **Daily Standup:** 09:30, Monday–Thursday  

The team works in **fixed-length sprints**:
- **Sprint Planning:** At the start of each sprint, Team Features and Tasks are planned in GitHub  
- **Sprint Review & Demo:** At the end of each sprint, progress is reviewed and completed work is showcased
