## Hovedtyper av informasjon

Tjenesten **Min Eiendom** viser og benytter hovedsakelig følgende typer informasjon:

- Eiendom
- Eiendomsstørrelse
- Bebygd areal
- Adresse
- Matrikkelnummer (Gnr/Bnr)
- Sak
- Saksdokumenter
- Reguleringsplaner
- Søppeltømming

---

## Forklaring av hver informasjonstype

- **Eiendom**  
  Generell informasjon om en spesifikk eiendom, inkludert eiendomsstørrelse, bebygd areal, adresse og matrikkelnummer (Gnr/Bnr).

- **Eiendomsstørrelse**  
  Det totale arealet til eiendommen, målt i kvadratmeter.

- **Bebygd areal**  
  Hvor mye av eiendommens tillatte byggeareal som allerede er bebygd.

- **Adresse**  
  Den offisielle adressen til eiendommen.

- **Matrikkelnummer (Gnr/Bnr)**  
  En unik identifikator for eiendommer i Norge, som består av gårdsnummer (Gnr) og bruksnummer (Bnr).

- **Sak**  
  En byggesak eller plansak knyttet til eiendommen, for eksempel byggesøknader eller tillatelser.

- **Saksdokumenter**  
  Dokumenter knyttet til tidligere og pågående saker for eiendommen, som søknader, vedtak og vedlegg.

- **Reguleringsplaner**  
  Regler og bestemmelser som gjelder for området rundt eiendommen. Disse planene beskriver hva som kan bygges, hvordan det kan bygges, og hvor det er tillatt å bygge.

- **Søppeltømming**  
  Informasjon om tidspunkter for henting og tømming av avfall, som restavfall, papir/papp og plast.

---

## Hvordan informasjonstypene henger sammen

- Eiendommen er det sentrale elementet og knytter all annen informasjon sammen.
- En eiendom kan ha flere saker knyttet til bygging, planlegging eller andre kommunale prosesser.
- Hver sak kan inneholde flere dokumenter, som søknader, vedtak og vedlegg.
- Reguleringsplaner gjelder for området der eiendommen ligger og bestemmer hva som er tillatt å bygge på eiendommen.
- Samlet gir disse informasjonstypene brukeren en helhetlig oversikt over eiendommen, juridiske begrensninger og sakshistorikk.
