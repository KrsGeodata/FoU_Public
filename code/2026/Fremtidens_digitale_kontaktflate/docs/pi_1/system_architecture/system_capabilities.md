### **Hva systemet skal gjøre**

Systemet skal gi brukere enkel tilgang til relevant informasjon om egen eiendom. Brukerne skal kunne finne, forstå og bruke informasjonen uten behov for forkunnskap eller veiledning fra kommunen.

Systemet skal gjøre det mulig for brukere å:

- Finne og se informasjon om egen eiendom på en oversiktlig måte
- Tydelig og lett navigering til relevant informasjon
- Få forklaringer på begreper og data som kan være vanskelige å forstå
- Tilgang til eiendomsskatt og kommunale avgifter
- Oversikt over naboliste og mulighet for å sende nabovarsel
- Sjekke avfall og tømming
- Forstå regler, planer og forhold som påvirker eiendommen
- Finne tydelig veiledning for videre handling, som kontakt eller neste steg
- Oppleve løsningen som enkel å bruke på både mobil og pc
