# Sprint Planning – Sprint 5 - 12.04.26 – 07.05.26

## Sprintmål

> Målet for denne sprinten er å videreutvikle løsningen med støtte for tematitler, slik at saksbehandler kan velge forhåndsdefinerte bestemmelsestitler med tilhørende metadata og dynamiske inputfelt. Sprinten skal også omfatte automatisering av bildeillustrasjoner basert på valgt tematittel, slik at relevante illustrasjoner vises automatisk. I tillegg er et sentralt mål å kvalitetssikre og teste løsningen. Rapporten skal også ferdigstilles fullstendig i løpet av denne sprinten.

---

## Avklaringer og risiko

| Type | Beskrivelse |
|---|---|
| Avklaring | Avklare hvilke tematitler som skal være forhåndsdefinert i løsningen. |
| Avklaring | Avklare hvordan dynamiske inputfelt og metadata skal genereres basert på valgt tematittel. |
| Avklaring | Avklare hvordan bildeillustrasjoner skal kobles til de ulike tematitlene. |
| Avklaring | Avklare hvilke deler av løsningen som skal prioriteres i testing og kvalitetssikring. |
| Risiko | Automatisering av tematitler, metadata og dynamiske felter kan være mer krevende enn forventet. |
| Risiko | Koblingen mellom tematitler og illustrasjoner kan bli ufullstendig eller feil. |
| Risiko | Ferdigstilling av rapporten kan ta mye tid og redusere kapasiteten til videre utvikling og testing. |

---

## ✅ Definition of Done

- [ ] Saksbehandler kan velge mellom forhåndsdefinerte tematitler i løsningen.
- [ ] Relevante inputfelt og metadata genereres dynamisk basert på valgt tematittel.
- [ ] Bildeillustrasjoner vises automatisk ut fra valgt tematittel.
- [ ] Løsningen er kvalitetssikret og testet.
- [ ] Rapporten er ferdigstilt.
