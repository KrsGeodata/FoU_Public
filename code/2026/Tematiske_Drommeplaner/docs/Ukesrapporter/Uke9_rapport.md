<details>
  <summary><strong>Fredag 27.02 – Logisk struktur, frontend og planlegging</strong></summary>

- Videre arbeid med logisk struktur for veileder og informasjonsflyt.
- Påbegynt frontend-arbeid for popup, med fokus på hvordan relevant informasjon kan presenteres tydelig innenfor begrenset plass.
- Planlegging av neste ukes arbeid.
- Oppdatering og strukturering av backlog.

- Diskusjon rundt planhierarki i videreutvikling av Drømmeplan:
  - PlanID (f.eks. 991C) er alltid overordnet.
  - Planen deles inn i felt (f.eks. B1), som igjen inneholder tomter (f.eks. tomt 9).
  - Drøftet om TomtNavn bør ha en mer sentral rolle i datamodell og presentasjon, ettersom det er på tomtenivå brukeren trenger mest presis informasjon.
  - Målet er å unngå for grov generalisering av metadata og bestemmelser, og sikre at strukturen samsvarer med hvordan regelverket faktisk oppleves av den enkelte eiendomseier.

Arbeidsdag: 09:00–15:00
