# Mikrodrømmeplan – Functional Scope (MoSCoW)

This document defines the functional scope of **Mikrodrømmeplan** using the MoSCoW prioritization method.  
The goal is to clarify what the solution must, should, could, and will not provide from a user perspective.

Mikrodrømmeplan is a lightweight guidance tool that helps users quickly understand whether a planned building measure (e.g. garage, shed, extension) is likely permitted or application-required, based on property-related regulations.

---

## Must Have

These features are essential for the solution to fulfill its purpose.

- Allow the user to select or enter an address
- Display a popup with property-specific, relevant information
- Clearly communicate whether a selected measure is:
  - likely allowed without application
  - likely application-required
  - or uncertain
- Provide a short and understandable explanation of why the result is given
- Present information in a clear, structured and scannable format
- Show only the most relevant rules and limitations for the selected measure
- Use terminology adapted to non-expert users
- Provide a direct link to the relevant zoning plan or municipal document
- Make it clear what the user should do next (e.g. read plan, contact municipality)
- Work without requiring users to interpret maps or legal texts
- Be usable without logging in or prior knowledge

---

## Should Have

These features add value and improve clarity but are not strictly required.

- Allow users to choose between different measures (garage, shed, extension)
- Present summarized key data related to the property (e.g. zoning purpose, building limits)
- Clearly separate important information from supplementary details
- Communicate assumptions and limitations of the guidance
- Use visual hierarchy to highlight the most important information first
- Ensure basic accessibility principles (readability, contrast, spacing)
- Be designed so the popup can be reused in other municipal solutions

---

## Could Have

These features are optional and may be included if time allows.

- Provide examples to help users understand regulations
- Offer alternative suggestions if a planned measure is not allowed
- Adapt explanations based on user input
- Support mock or simulated data for demonstration purposes
- Allow the solution to be extended with real data sources in the future
- Present a simple confidence indicator (e.g. high / medium / low certainty)

---

## Won’t Have

These features are explicitly out of scope.

- Full legal validation or guarantees of approval
- Replacement of formal application processes
- Interactive maps or GIS functionality
- Automatic submission of building applications
- Display of full legal texts or complete plan documents inside the popup
- Real-time integration with all municipal systems

---

## Notes

- Mikrodrømmeplan is a guidance tool, not a legal authority.
- The solution focuses on reducing uncertainty and time spent searching for information.
- The popup is intended as a decision-support aid, not a final answer.
- Scope and prioritization may evolve based on testing and insights.
