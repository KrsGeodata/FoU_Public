# FoU 2026 - MVP Archive

Denne katalogen inneholder de fire MVP-ene som ble utviklet gjennom Kristiansand kommunes FoU-program i 2026.

Prosjektene ble gjennomført som reelle utviklingsoppgaver med utgangspunkt i faktiske behov innen plan-, byggesaks- og innbyggertjenesteområdet.


| Project | Year | Type |
|----------|------|------|
| Tematiske Drømmeplaner | 2026 | AI / Planning |
| Lokal LLM for Saksbehandlere | 2026 | AI Assistant |
| DiBK Veiviser m/TiltaksAID | 2026 | Building Permit Guidance |
| Fremtidens Digitale Kontaktflate | 2026 | Citizen Services |


## Prosjekter

### Tematiske Drømmeplaner

Utforsker hvordan generativ KI kan brukes til å utvikle tematiske planforslag og alternative fremtidsbilder basert på kommunale data, planverk og brukerbehov.

Katalog:

```text
Tematiske_Drommeplaner/
```

---

### Lokal LLM for Saksbehandlere

Undersøker hvordan lokale språkmodeller kan benyttes som arbeidsverktøy for saksbehandlere med fokus på datakontroll, personvern og kommunale arbeidsprosesser.

Katalog:

```text
Lokal_LLM_for_Saksbehandlere/
```

---

### DiBK Veiviser med TiltaksAID

Videreutvikling og utforsking av digitale veivisere for plan- og byggesaksområdet basert på eksisterende erfaringer fra TiltaksAID-konseptet.

Katalog:

```text
DiBK_veiviser_m_TiltaksAID/
```

---

### Fremtidens Digitale Kontaktflate

Utforsker hvordan kommunale tjenester kan presenteres gjennom en samlet digital kontaktflate med integrasjon mot flere kommunale datakilder og tjenester.

Katalog:

```text
Fremtidens_digitale_kontaktflate/
```

## Om arkivet

Prosjektene i denne katalogen er publisert som historiske snapshots av de opprinnelige utviklingsrepositoriene.

Snapshotene representerer prosjektstatus ved avslutningen av FoU-programmet i 2026.

Historikk, utviklingsforløp, arbeidskopier, CI/CD-konfigurasjon og interne prosjektartefakter er ikke nødvendigvis inkludert.

Se:

```text
SOURCE_SNAPSHOT.md
```

for detaljer om hvordan arkivet er etablert.

## Ansvarsfraskrivelse

Prosjektene publiseres for:

* dokumentasjon
* læring
* kunnskapsdeling
* videre forskning og eksperimentering

Koden må vurderes, testes og kvalitetssikres før eventuell bruk i produksjonsmiljøer.
