# FoU Program Source Archive

Denne katalogen inneholder kildekode, dokumentasjon og rapporter produsert gjennom Kristiansand kommunes FoU-program.

Formålet med arkivet er å dokumentere eksperimenter, forskningsprosjekter, studentoppgaver og MVP-er utviklet gjennom programmet. Innholdet representerer ulike modenhetsnivåer, fra tidlige konsepter og prototyper til mer komplette demonstratorer.

## Viktig

Dette arkivet publiseres som dokumentasjon og kunnskapsdeling.

Prosjektene:

* leveres uten garantier
* er ikke nødvendigvis produksjonsklare
* kan inneholde eksperimentell kode
* vedlikeholdes normalt ikke etter avsluttet FoU-periode

Målet er å vise arbeidsformer, løsningsretninger, arkitekturvalg og læringsutbytte fra FoU-programmet.
