## Om KartAI

KartAI er et offentlig innovasjonsinitiativ hvor kommuner, akademia, studenter og næringsliv samarbeider om å utforske og utvikle nye digitale løsninger innen:

- Plan og byggesak
- Geodata
- Kunstig intelligens
- Digitalisering av offentlig sektor

Målet er å redusere avstanden mellom forskning, innovasjon og praktisk anvendelse.

Gjennom programmet arbeides det systematisk med å koble:

- Faglige behov
- Studentprosjekter
- Forskning
- Teknologi
- Praktisk gjennomføring

slik at resultatene kan videreutvikles og tas i bruk både lokalt og nasjonalt.

---

## Årets MVP-portefølje (2026)

### Lokal LLM for Saksbehandlere

Utforsker hvordan lokale språkmodeller og moderne KI-arkitektur kan gi saksbehandlere trygg og relevant beslutningsstøtte basert på kommunens egne data og arbeidsprosesser.

### Tematisk Drømmeplan

Utforsker hvordan komplekse reguleringsplaner kan struktureres og presenteres på en måte som gjør dem enklere å forstå og bruke for både innbyggere og kommune.

### DiBK Veiviser med TiltaksAID

Utforsker hvordan geodata, eiendomsdata og KI-basert veiledning kan gjøre plan- og byggesaksprosesser enklere og mer tilgjengelige.

### Fremtidens Digitale Kontaktflate (Min Eiendom)

Utforsker hvordan kommunale tjenester, data og informasjon kan samles i en mer helhetlig og personlig digital innbyggerflate.

## Fra FoU til videre verdiskaping

En sentral ambisjon i KartAI er å redusere avstanden mellom:

- Utdanning
- Forskning og utvikling
- Offentlig sektor
- Leverandørmarkedet

MVP-ene representerer ikke ferdige produkter, men dokumenterte løsningsretninger utviklet med utgangspunkt i reelle behov.

For flere av løsningene vil videre arbeid kunne skje gjennom:

- Nye studentprosjekter
- Forskning
- Kommunale utviklingsløp
- Leverandørinitiativ
- Samarbeid mellom flere offentlige aktører

---

## Leverandørwebinar – Fra FoU til marked

Som en direkte oppfølging av KartAI-avslutningen inviterer Kristiansand kommune i samarbeid med DiBK til et åpent leverandørwebinar.

Målet er å redusere avstanden mellom:

- Kommunale behov
- Studentenes FoU-arbeid
- Leverandørmarkedets evne til å videreutvikle gode løsninger

Leverandører får tilgang til:

- Problemforståelser
- MVP-er
- Arkitektur
- FoU-resultater
- Dialog med teamene bak løsningene

Webinaret er ikke en anskaffelse og innebærer ingen forpliktelser.

Målet er å skape dialog rundt konkrete behov, løsningsretninger og videre utviklingsmuligheter.

Mer informasjon:

👉 https://labs.geokrs.no
